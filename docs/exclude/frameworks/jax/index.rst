***********
JAX on ROCm
***********

`JAX <https://jax.readthedocs.io/>`__ is a library for array-oriented numerical
computation with automatic differentiation and JIT compilation via XLA. ROCm
support enables high-performance machine learning research on AMD GPUs.

* :doc:`Install JAX <install>` — install ROCm-enabled JAX libraries for your
  AMD GPU.
