***************
PyTorch on ROCm
***************

`PyTorch <https://pytorch.org/>`__ is an open-source deep learning framework
providing GPU-accelerated tensor computation and automatic differentiation.
ROCm support for PyTorch is upstreamed into the official PyTorch repository,
enabling training and inference on AMD GPUs.

* :doc:`Install PyTorch <install>` — install a ROCm-enabled PyTorch build for
  your AMD GPU.
