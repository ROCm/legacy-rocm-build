********************
ROCm media libraries
********************

ROCm media libraries provide GPU-accelerated video decoding and image
processing capabilities for AMD GPUs.

* :doc:`rocDecode <rocdecode:index>` -- High-performance SDK for access to
  video decoding features on AMD GPUs.

* :doc:`rocJPEG <rocjpeg:index>` -- Library for decoding JPG images on AMD
  GPUs.
