*************************************
AMD data center GPU system acceptance
*************************************

To configure, validate, benchmark, and baseline AMD data center GPU platforms
for customer acceptance and production deployment, see the
`AMD data center GPU customer acceptance guide
<https://instinct.docs.amd.com/projects/system-acceptance/en/latest/index.html>`_.

Per-GPU acceptance guidance is available for the following AMD data center
GPUs:

* `AMD data center GPU MI355X <https://instinct.docs.amd.com/projects/system-acceptance/en/latest/gpus/mi355x.html>`_
* `AMD data center GPU MI350X <https://instinct.docs.amd.com/projects/system-acceptance/en/latest/gpus/mi350x.html>`_
* `AMD data center GPU MI325X <https://instinct.docs.amd.com/projects/system-acceptance/en/latest/gpus/mi325x.html>`_
* `AMD data center GPU MI300X <https://instinct.docs.amd.com/projects/system-acceptance/en/latest/gpus/mi300x.html>`_
